# Magnific exercise guide recreation

This review library contains all nine narrated drafts, including the six additional exercises.

These guides reuse the existing Marin AAC audio unchanged and the existing nine instruction cues. Magnific Seedance 2.0 produces short source movements; build.py assembles slowed movement, resting frames and holds to match the narration. Heel-slide return footage is also played backwards to show the outward slide. Seated extension uses a correct resting reference image; its extension footage is reversed for the controlled return to the floor.

Rejected sources are not used: the first straight-leg raise lifted too high; the first seated extension lifted the thigh; the second seated extension never returned to the floor.

verification.json records full video decoding and byte-identical original audio checks. Browser playback was checked locally. These are visual drafts, not clinical validation. No published guides have been replaced.

## Additional guides

Quad set, standing knee bend, mini squat, sit to stand, squat and single-leg balance use the original full Marin audio and cue text. See additional-sources.json and timing.json for clip provenance and movement trims.

Standing knee bend remains a draft with a visible discrepancy: the animation uses a fixed support frame while the existing narration refers to a worktop. This is labelled on the preview and needs correction before patient release.
